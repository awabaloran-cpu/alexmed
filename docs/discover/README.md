# 🧭 اكتشف (Discover)

كتالوج اختبارات جاهزة: يدرسها الطالب وحده («تعلّم»، «البطاقات») أو يلعبها مع
أصدقائه في غرفة دراسة. كل شيء بلغة واحدة في المرة: العربية أو الإنجليزية.

## أين كل شيء

| المسار | ما فيه |
|---|---|
| `drizzle/schema.ts` + `0051_discover.sql` | `discover_channels`, `discover_quizzes`, `discover_questions`, `discover_sections`, `discover_channel_follows` — جداول جديدة فقط |
| `lib/discover/data.ts` | قراءة الصفحة، البحث، ورقة الاختبار، القناة، المتابعة، عدّ مرات اللعب |
| `lib/discover/seed-*.json` + `seed.ts` | أول محتوى: 6 قنوات، 40 اختبارًا (20 عربي + 20 إنجليزي، 331 سؤالًا)، وأقسام الصفحة |
| `lib/discover/i18n.ts` | كل نصوص الواجهة بالعربية والإنجليزية؛ اختبار يمنع أي نص عربي داخل ملفات الشاشات |
| `lib/discover/study.ts` | قواعد النجوم وجولة البطاقات والسحب (خالصة ومختبرة) |
| `lib/trpc/discoverRouter.ts` | `discover.page / search / quiz / questions / played / channel / follow` |
| `app/discover/` | الصفحة، `channel/[slug]`، `learn/[slug]`، `cards/[slug]` |
| `components/discover/` | البطاقات، الغلاف المرسوم، ورقة الاختبار، الصوت، مزوّد اللغة |

## الصفحة تُدار من الخادم

`discover_sections` تحدد الأقسام وترتيبها وما يملؤها. الأنواع:
`banner`، `partners` (قنواتنا)، `ranked_list`، `featured_collections`،
`learn_cards`، `channel_block`، `horizontal_cards`. الحقل `filter` (jsonb):
`category`، `tag`، `channelSlug`، `quizSlugs`، `sort` (`popular`/`newest`)،
`limit`، و`banners` / `collections` لنوعيهما. `language` فارغ = القسم في
اللغتين. تغيير صف يغيّر الصفحة للجميع بلا نشر جديد؛ نوع لا يعرفه الكود
يُتجاهل بصمت.

## اللعب مع الأصدقاء

لا نظام جديد: زر «العب مع الأصدقاء» ينشئ غرفة خاصة للطالب (أو يستخدم غرفته
المفتوحة) ويفتحها بـ`?quiz=<slug>`. تظهر في الغرفة بطاقة «اختبار جاهز»، وعند
الضغط يبدأ `rooms.startCatalogQuiz` — نفس محرّك الاختبار الجماعي
(`lib/study-rooms/quiz.ts`): الجواب الصحيح لا يغادر الخادم قبل الكشف، 100
نقطة + حتى 50 للسرعة، ترتيب بعد كل سؤال، ومنصة للثلاثة الأوائل في النهاية.
الاختبار الذي بلا ملف (`bookId` فارغ) تُقرأ أسئلته من `discover_questions`.

## الأغلفة والصوت

- **الأغلفة مرسومة** (`Cover.tsx`): لون الاختبار + أيقونة موضوعه. لا صور
  تُحمَّل. عمودا `coverImage` / `logo` / `cover` جاهزة لصور حقيقية لاحقًا،
  وإن فشل تحميل صورة يعود الرسم.
- **الصوت مولَّد في المتصفح** (`sound.ts`، Web Audio): مؤثرات القلب والسحب
  والصح والخطأ والنهاية، وموسيقى خلفية هادئة. لا ملفات ولا تراخيص. الموسيقى
  مطفأة افتراضيًا، تتوقف عند إخفاء الصفحة أو مغادرتها، والاختياران محفوظان
  على الجهاز.

## مرات اللعب

تبدأ من صفر وتُعدّ فعليًا: مرة كل 30 دقيقة لكل طالب واختبار في «تعلّم»
و«البطاقات» (العدّ في ذاكرة الخادم)، ومرة عند بدء لعبة في غرفة. «اخترنا لك»
مرتّبة بالأكثر لعبًا.

## لم يُبنَ / يحتاج المالك

- واجهة إدارة لإضافة اختبارات أو تعديل الأقسام (الآن عبر ملفات الـseed أو
  قاعدة البيانات مباشرة).
- صور أغلفة حقيقية، وشاشات Flutter.
- الاهتزاز لا يعمل في متصفح iPhone (لا واجهة له هناك).
- فلتر «المناسبات» مبني على وسوم تبدأ بـ`occ:`.
